BurnerPhone for Windows 10 / 11.

**Install:** download **`BurnerPhone-Setup.exe`** below and run it. It installs just for you (no admin), adds a Start menu shortcut and sits in the tray. Press **Alt+Q** in any game and run the game borderless windowed.

No installer wanted? Take **`burnerphone-windows.zip`**, unzip it anywhere and run `BurnerPhone\BurnerPhone.exe`.
