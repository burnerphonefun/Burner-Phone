BurnerPhone for Windows 10 / 11.

**Install:** download **`BurnerPhone-Setup.exe`** below and run it. It installs just for you (no admin), adds a Start menu shortcut and sits in the tray. Press **Alt+Q** in any game and run the game borderless windowed.

No installer wanted? Take **`burnerphone-windows.zip`**, unzip it anywhere and run `BurnerPhone\BurnerPhone.exe`.

**New in v2.5**

- **any amount:** tap the buy size, "buy any" or "any %" and type the SOL or the % on the phone's own keypad (quick picks too). Works on paper and with your own wallet
- **a normal installer:** per user, no admin, uninstall from Windows settings. The zip is still here
- **built by GitHub, not on someone's PC:** this release came out of the release workflow on a GitHub runner, with a build certificate you can check (below)

From 2.4: copycat bursts fold into one "×N" row, the pixel phone and the PDA show every notification, and the game detector is a tiny Rust helper.
