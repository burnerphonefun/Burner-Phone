BurnerPhone for Windows 10 / 11.

**Install:** download **`BurnerPhone-Setup.exe`** below and run it. It installs just for you (no admin), adds a Start menu shortcut and sits in the tray. Press **Alt+Q** in any game and run the game borderless windowed.

No installer wanted? Take **`burnerphone-windows.zip`**, unzip it anywhere and run `BurnerPhone\BurnerPhone.exe`.

**New in v2.6**

- **live on [burnerphone.fun](https://burnerphone.fun):** the app gets its live coins from the new home. Older versions keep working for now; update when you can
- **the new mark:** the app icon and the tray icon are the phone from [@burnerphonefun](https://x.com/burnerphonefun)
- **a proper name on the file:** the exe's properties say BurnerPhone instead of "burner"

From 2.5: type any amount on the phone's keypad, a normal per-user installer, releases built by GitHub with a build certificate you can check (below).
